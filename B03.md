# B03 - Day 5-6 - Hotel & RoomType Management

Branch target: `feature/hotel-roomtype-management`

Goal: admin quan ly hotel; owner quan ly room type thuoc hotel cua minh; public co skeleton lay chi tiet hotel/room type.

## Scope

- UI target: admin hotels page, owner room types page, hotel detail skeleton.
- Backend modules: `HotelModule`, `RoomTypeModule`, `PublicHotelModule`.
- Data: `hotels`, `room_types`.
- Guards: RBAC permission guard da co; ownership guard chua thay enforce trong code hien tai.
- Seed: `src/databases/seed/rbac.seed.ts` co permission `hotel.*`, `room_type.*` va role `HOTEL_OWNER`.

## Endpoint Map

### Admin Hotels

Controller: `src/modules/hotel/hotel.controller.ts`

- `POST /admin/hotels`
  - Permission: `hotel.create`
  - Handler: `HotelController.create(dto: CreateHotelDto)`
  - Service: `HotelService.create(dto: CreateHotelDto): Promise<HotelEntity>`

- `GET /admin/hotels/:hotelId`
  - Permission: `hotel.read`
  - Handler: `HotelController.findById(hotelId: string)`
  - Service: `HotelService.findById(hotelId: string): Promise<HotelEntity>`

- `PATCH /admin/hotels/:hotelId`
  - Permission: `hotel.update`
  - Handler: `HotelController.update(hotelId: string, dto: UpdateHotelDto)`
  - Service: `HotelService.update(hotelId: string, dto: UpdateHotelDto): Promise<HotelEntity>`

- `DELETE /admin/hotels/:hotelId`
  - Permission: `hotel.delete`
  - Handler: `HotelController.remove(hotelId: string)`
  - Service: `HotelService.remove(hotelId: string): Promise<{ deleted: true }>`

- `PATCH /admin/hotels/:hotelId/owner`
  - Permission hien tai: `role.assign_permission`
  - Handler: `HotelController.assignOwner(hotelId: string, dto: AssignHotelOwnerDto)`
  - Service: `HotelService.assignOwner(hotelId: string, dto: AssignHotelOwnerDto): Promise<HotelEntity>`
  - Note: requirement ghi `PATCH /admin/hotels/:id/owner`; code dung param `hotelId`.

### Owner Room Types

Controller: `src/modules/room-type/room-type.controller.ts`

- `POST /owner/room-types`
  - Permission: `room_type.create`
  - Handler: `RoomTypeController.create(dto: CreateRoomTypeDto)`
  - Service: `RoomTypeService.create(dto: CreateRoomTypeDto): Promise<RoomTypeEntity>`

- `GET /owner/room-types?hotelId=:hotelId`
  - Permission: `room_type.read`
  - Handler: `RoomTypeController.findByHotel(hotelId: string)`
  - Service: `RoomTypeService.findByHotelId(hotelId: string): Promise<RoomTypeEntity[]>`

- `GET /owner/room-types/:id`
  - Permission: `room_type.read`
  - Handler: `RoomTypeController.findById(id: string)`
  - Service: `RoomTypeService.findById(id: string): Promise<RoomTypeEntity>`

- `PATCH /owner/room-types/:id`
  - Permission: `room_type.update`
  - Handler: `RoomTypeController.update(id: string, dto: UpdateRoomTypeDto)`
  - Service: `RoomTypeService.update(id: string, dto: UpdateRoomTypeDto): Promise<RoomTypeEntity>`

- `DELETE /owner/room-types/:id`
  - Permission: `room_type.delete`
  - Handler: `RoomTypeController.remove(id: string)`
  - Service: `RoomTypeService.remove(id: string): Promise<{ deleted: true }>`

### Public Hotel Detail Skeleton

Controller: `src/modules/room-type/public-hotel.controller.ts`

- `GET /hotels/:id/room-types`
  - Public: yes
  - Handler: `PublicHotelController.findRoomTypes(hotelId: string)`
  - Service: `PublicHotelService.getRoomTypes(hotelId: string)`
  - Response shape hien tai: `{ hotel, roomTypes }`, trong do hotel chi select `id`, `name`, `city`.

- Gap: requirement co `GET /hotels/:id`, nhung code hien tai chua co endpoint public rieng cho hotel detail.

## Acceptance Checklist

- Admin tao hotel duoc: `POST /admin/hotels`.
- Admin update/delete hotel duoc: `PATCH`, `DELETE /admin/hotels/:hotelId`.
- Admin assign owner duoc: `PATCH /admin/hotels/:hotelId/owner`.
- Owner tao room type duoc: `POST /owner/room-types`.
- Owner CRUD room type theo hotel duoc: `/owner/room-types`.
- Soft delete dung TypeORM `softDelete` cho hotel va room type.
- Cache invalidation da co khi update/delete hotel va room type.

## Gaps Before Continuing

- Chua co ownership guard: owner co permission `room_type.*` co the truyen `hotelId` bat ky neu biet id.
- Chua co public `GET /hotels/:id`; chi co `GET /hotels/:id/room-types`.
- `PATCH /admin/hotels/:hotelId/owner` dung permission `role.assign_permission`; nen xem lai co can permission rieng nhu `hotel.update` hay `hotel.assign_owner`.
- `HOTEL_OWNER` trong seed dang co ca `hotel.create/update/delete`; neu yeu cau chi admin quan ly hotel, can siết role.
- `RoomTypeRepository.findByHotelId()` va `findAll()` khong filter `status`/soft deleted ro rang trong query, nhung TypeORM mac dinh khong lay soft deleted neu entity co `DeleteDateColumn`.
- Chua thay migration file trong repo; hien tai co ve dung TypeORM synchronize/config runtime.
