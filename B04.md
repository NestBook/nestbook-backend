# B04 - Day 7-8 - Search, Availability, Booking Quote

Branch target: `feature/search-availability-quote`

Goal: search tra phong con trong; quote tinh dung gia va availability; owner quan ly availability block.

## Scope

- UI target: hotel search page, filter UI, quote preview, owner availability page.
- Backend modules: `HotelSearchService`, `AvailabilityModule`, `BookingModule`.

## Important Function Signatures

### Hotel Search Service

File: `src/modules/hotel/hotel-search.service.ts`

```ts
async search(query: any): Promise<Array<{ id: string; rooms: any[] }>>
private group(rows: any[]): Array<{ id: string; rooms: any[] }>
```

Logic hien tai:

```ts
const quantity = Number(query.quantity ?? 1);
const minPrice = query.minPrice ? Number(query.minPrice) : undefined;
const maxPrice = query.maxPrice ? Number(query.maxPrice) : undefined;
const checkIn = query.checkInDate ? new Date(query.checkInDate) : null;
const checkOut = query.checkOutDate ? new Date(query.checkOutDate) : null;
```

Flow:

- Lay tat ca room type bang `RoomTypeService.findAll()`.
- Filter `minPrice`, `maxPrice`, `roomType`.
- Neu co `checkInDate` va `checkOutDate`, goi `AvailabilityService.check(...)`.
- Bo qua room type neu `availability.canBook` false.
- Group ket qua theo `hotelId`.

### Booking Service

File: `src/modules/booking/booking.service.ts`

```ts
async quote(dto: BookingQuoteDto): Promise<BookingQuoteResponse>
private calculateNights(checkInDate: string, checkOutDate: string): number
```

Formula hien tai:

```ts
nights = (checkOut - checkIn) / (1000 * 60 * 60 * 24)
roomSubtotal = roomType.price * nights * dto.quantity
hotelVoucherDiscount = 0
platformVoucherDiscount = 0
discountAmount = hotelVoucherDiscount + platformVoucherDiscount
finalAmount = roomSubtotal - discountAmount
```

### Availability Engine

File: `src/modules/availability/strategies/availability.engine.ts`

```ts
async calculate(ctx: AvailabilityContext): Promise<AvailabilityResult>
```

Formula hien tai:

```ts
total = await bookingAggregation.getTotal(ctx.roomTypeId)
blocked = await blockStrategy.getBlocked(ctx)
held = await holdStrategy.getHeld()
booked = 0
available = total - booked - held - blocked
canBook = available >= ctx.quantity
```

## Acceptance Checklist

- Search theo date goi availability va chi tra room co `canBook = true`.
- Search theo price filter `room.price`.
- Search theo room type filter substring `room.name`.
- Quote quantity <= 0 -> `BadRequestError`.
- Quote date invalid, checkout <= checkin -> `BadRequestError`.
- Quote tinh `nights`, `roomSubtotal`, `finalAmount`.
- Quote tra `availableQuantity` va `canBook`.
- Create block lam giam availability neu date range overlap.
- Delete block tra `{ deleted: true }`.

## Gaps Before Continuing

- `GET /hotels/search` chua filter `city`, trong khi requirement co `Search city/price/date`.
- Search response chua include hotel name/city/address; chi co `hotelId` va rooms.
- Booking aggregation chua tru booked booking that; `booked = 0`.
- Redis hold chua tinh quantity held; `RedisHoldStrategy.getHeld()` return `0`.
- Owner availability/block endpoints chua co `@Permissions(...)` va chua enforce owner chi thao tac room type thuoc hotel cua minh.
- `createBlock()` chua validate date range, quantity min, room type ton tai, block quantity co vuot total quantity hay khong.
- `removeBlock()` dung hard delete, khong check block ton tai.
- `AvailabilityEngine` co the tra `available` am neu block/hold > total; can can nhac clamp ve `0`.
- DTO `CheckAvailabilityDto.quantity` chua co `@Min(1)`.
- Search query dang typed `any`; nen tao DTO rieng cho search.
